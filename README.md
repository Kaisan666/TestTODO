# TODO-лист

React + TypeScript + Vite, формы на react-hook-form, данные хранятся в localStorage.

## Возможности

- добавление задачи, сразу с пунктами (или без них);
- задачи — аккордеоны со стрелкой: внутри пункты, их можно отмечать, удалять и добавлять;
- редактирование задачи: название и список пунктов, отметки у оставшихся пунктов сохраняются;
- отметка выполнения задачи целиком (отмечает все пункты) или по пунктам — задача считается выполненной, когда готовы все её пункты;
- удаление задач;
- сохранение задач после обновления страницы и синхронизация между открытыми вкладками.

## Запуск

```bash
npm install
npm run dev
```

| Скрипт | Что делает |
|---|---|
| `npm run dev` | сервер разработки |
| `npm run lint` | oxlint |
| `npm run build` | проверка типов и сборка в `dist/` |
| `npm run preview` | просмотр собранной версии |

## Структура

- `src/hooks/useTasks.ts` — состояние задач: связывает редьюсер с React и localStorage, слушает изменения из других вкладок
- `src/lib/tasks.ts` — редьюсер и загрузка задач из localStorage с проверкой формы данных
- `src/lib/taskForm.ts` — общие для форм тип значений, правила для названия и очистка пунктов
- `src/lib/id.ts`, `storage.ts`, `cn.ts` — генерация id, чтение и запись JSON, склейка классов
- `src/components/AddTaskForm.tsx` — форма новой задачи (`useForm`)
- `src/components/EditTaskForm.tsx` — форма редактирования задачи (`useForm`)
- `src/components/StepFields.tsx` — список полей пунктов для обеих форм (`useFieldArray`)
- `src/components/TaskItem.tsx` — задача-аккордеон с пунктами
- `src/components/AddStepForm.tsx` — форма добавления пункта внутри задачи
- `src/components/Checkbox.tsx`, `icons.tsx` — чекбокс и иконки
- `src/index.css` — цветовые токены и базовые стили, `src/App.css` — стили компонентов

## Дизайн

Тема Midnight в палитре `#1B263B` и `#F72585`: тёмный фон `#1B263B`, розовые акценты со свечением. Под белым текстом кнопок используется более тёмный оттенок `#D6136C`, чтобы контраст был не ниже 4.5:1.
