# TODO-лист

React + TypeScript + Vite, формы на react-hook-form, данные хранятся в localStorage.

## Возможности

- добавление задачи, сразу с пунктами (или без них);
- задачи — аккордеоны со стрелкой: внутри пункты, их можно отмечать, удалять и добавлять;
- отметка выполнения задачи целиком (отмечает все пункты) или по пунктам — задача считается выполненной, когда готовы все её пункты;
- удаление задач;
- сохранение задач после обновления страницы.

## Запуск

```bash
npm install
npm run dev
```

## Структура

- `src/hooks/useTasks.ts` — состояние задач (reducer) и синхронизация с localStorage
- `src/components/AddTaskForm.tsx` — форма новой задачи (`useForm` + `useFieldArray` для пунктов)
- `src/components/TaskItem.tsx` — задача-аккордеон с пунктами
- `src/components/AddStepForm.tsx` — форма добавления пункта внутри задачи
- `src/index.css` — цветовые токены и базовые стили, `src/App.css` — стили компонентов

## Дизайн

Тема Midnight в палитре `#1B263B` и `#F72585`: тёмный фон `#1B263B`, розовые акценты со свечением.
